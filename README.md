# table

A command-line tool for AI agents that reads a CSV file and answers
questions about its shape, in [lex-sys](https://github.com/alpibrusl/lex-sys).
It is the first tool built outside
[lexsys-tools](https://github.com/alpibrusl/lexsys-tools), on that
repository's `contract/` consumed as a package.

Status: a skeleton is on the way (branch `skeleton`). This first commit only
names the project; see the design in lexsys-tools,
[`docs/next-tools.md` section 5](https://github.com/alpibrusl/lexsys-tools/blob/next-tools-design/docs/next-tools.md).
