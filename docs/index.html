CSV, answered exactly, or refused with a repair.

A small command-line tool that selects, filters, groups and aggregates CSV and TSV in one bounded pass, for agents and scripts. The same file gives the same bytes; a cell that is not a number is a named refusal, not a guess.

Bounded memory

The file is read in 64 KiB chunks. Peak memory is about 2 MB on a 31 MB file, and flat on a 1 GB one.

Exact, never a float

bytes:int > 50000 compares 64-bit integers. A sum past 64 bits is a refusal, not a wrap.

A rule for every refusal

A stable tag, an exit code, the row and column it found, and a repair when one exists.

cut, awk and sort | uniq do not know they are reading CSV.

They work until a field has a comma in it, or a cell is empty, or the file is big. An agent that runs them gets an answer either way, and cannot tell which kind it got. Below, the same five-line file.

cut and awk, on the file

$ cut -d, -f2,4 orders.csv

"Doe,200
Acme,
"Doe,200
Acme,128
Zed,64

$ awk -F, '{s+=$4} END {print s}' orders.csv

table, on the same file

$ table --select customer,bytes --format csv orders.csv
customer,bytes
"Doe, Jane",512
Acme,
"Doe, Jane",2048
Acme,128
Zed,64

$ table --agg sum:bytes --format csv orders.csv
table: value.not-integer: a cell is not an exact integer: an optional sign and digits, nothing else (an empty cell is not one)
sum:bytes
# exit status 8

The quoted comma in "Doe, Jane" moved every column after it: cut returned the wrong one, and awk summed status for two rows and bytes for the others, with the empty cell as a zero. Neither said anything. table gave the right columns, and refused to add up a cell that is not a number.

What goes wrongWhat table does
A quoted comma splits a fieldAn RFC 4180 reader of its own: quoted fields, doubled quotes, delimiters and newlines inside quotes, CRLF, a byte order mark. Checked against Python’s csv.
An empty or odd cell is silently a zeroAn :int column is exact 64-bit integers; anything else, an empty cell included, is value.not-integer naming its row, line and column.
Memory grows with the file or the keysMemory is the longest record, the header and one page of output. A grouping is bounded by three limits, each its own rule. On the 1M-row file the incumbents measured 20 to 337 MB; table 2 MB (see numbers).
The error is prose, and the repair is a guessA rule tag that does not change, an exit code, and a repair that is either a whole command to run, a retry, or an honest “none”.
The answer changes with the order or the threadsGroups come out in key order, and --threads N gives the sequential bytes, the same refusal included.

How it works

One plan, one engine, one pass. The flags do not each do something: they fill one query, resolved against the header before any row is read, so a refusal about a column costs one line, not a scan.

A refusal, as the tool prints it

Not an English sentence to parse: a tag, an exit status, the detail, and a repair. The first one names the header and carries the corrected command. The second names the row, the line and the column; its repair is “none” because what the cell was meant to be is not known, and the hint says how to say which rows you mean.

We try to break it.

The adversarial round looked for the shapes of file and question that are not kind to table: 16 cells, written down before any of them was run (the first commit of docs/adversarial.md is the registration), with the incumbents, how each is run, what counts as a loss (a ratio above 1.25 is a material one) and a prediction for each. Every loss is reported with its ratio and its cause, and nothing was tuned to avoid one.

Where it fits, and where it does not

A tool for the questions an agent asks of one file, where a wrong answer is worse than a refusal. It is not trying to replace the tools below; the second column is what each is for.

What it is forWhat you give up to use it
tableShape, columns, filtered rows, counts and exact integer sums by group, of one CSV or TSV, bounded and repeatable.No row sort yet, no joins, no floats or decimals, no type inference, no JSON lines, no stdin, no --query.
csvtkA CSV toolkit: cut, filter, freq, summary, sort. Computes floats; sorts rows.Memory: summary used 11.8 to 14.8 GB on sums with 100,000 or a million keys. Exactness and refusals are not its aim.
MillerA whole language over records, in many formats.Much more memory here (110 to 337 MB on the 31 MB file) and more time on these questions.
DuckDBSQL, a planner, joins, window functions, spill to disk, typed columns, type inference, Parquet and JSON readers.It is a database engine; table does a small part of what it does. DuckDB wins the high-cardinality groupings by 3x and more.
pandasArbitrary computation over a table.Arbitrary code is unbounded; giving that up is what keeps this tool bounded.

Built for

  • An agent that has to answer a question about a file and know the answer is right
  • Scripts that need the same bytes on every run
  • Files that may be large, quoted, or damaged

Not for

  • Joins, a row sort, window functions
  • Floats, dates, decimals
  • Parquet, JSON lines, a pipe on standard input

What you get

The shape

Headers, column and row counts, and whether --max-rows cut the count.

Select

By name, in the order given, or by position (#3); a repeated name repeats the column. An ambiguous name is refused.

Filter

= != < <= > >= contains in (...) joined by and. Text is bytewise; :int is exact.

Group and aggregate

count, sum, min, max, distinct, with --sort and --top, as JSON or CSV.

Pages

JSON pages with a cursor and a byte budget; CSV streamed as it is read.

Threads

--threads N, 1 to 64, with the sequential answer byte for byte.

Limits with rules

Rows, line and record size, groups, distinct values and group state are each bounded, each its own rule.

Built in lex-sys, with an authority the compiler wrote

lex-sys is a typed systems language whose compiler writes down what a program may do. For this tool that report is the row below: it is derived over the sources and the installed contract package, embedded in the binary, kept in manifests/table.authority.json, and CI fails when the binary says something else or when it exceeds the ceiling a person reviews in tools.toml. No network, no foreign function, no clock, and nothing written to disk: a new capability would be a change somebody has to approve.

# manifests/table.authority.json, as `python3 scripts/manifest.py --check` prints it
table    args, conc, dir_read, err_write, file_read, fs_read(""), heap, io_write
# bounded: true; foreign symbols: none; net_out, net_in, ffi, clock: absent
labelwhat it lets the program do (the gloss is hand-written)
argsreads its command line
concthreads, for --threads
dir_readdirectory reads, to open the path
err_writewrites standard error
file_readreads the input file
fs_read("")a path given at run time
heapallocates memory
io_writewrites standard output

The row is generated from the committed manifest, and the script checks it is what table introspect prints and that it holds no net_out, net_in, ffi or clock. The authority says what the program may do, not that it is correct: that is the tests’ job (evidence). table is built on lexsys-tools’ contract, taken as a package.

Small and bounded

The file is the design’s benchmark: 1,000,000 rows of id,status,bytes,path,note (the last quoted), seeded, 31,667,311 bytes. Minimum of 5 interleaved runs, output to /dev/null, peak memory from /usr/bin/time, and every contender’s answer checked against one computed in Python before any timing. One file, two integer columns, one low-cardinality group key: that is the whole claim.

Early: what is built, and what is not

  • Built and tested: the shape, --select, --where, --group and --agg, --sort and --top of the groups, --threads. Not built: a row sort (a branch is in progress), JSON lines, joins, --query, stdin, mean and describe, decimals, a second sort key, or. The list, in the order it would be taken.
  • The measurements are of one file shape on two machines, plus the 16 adversarial cells. The mutant lists for --select and --where are stale (their code moved) and have not been run since; the lists for --threads and the cell-cost paths are current.
  • High-cardinality groupings are the known weakness, and --threads should not be used for them.
  • It is one of the first tools built outside lexsys-tools on its contract package, on a compiler that is itself changing: the sources pin a compiler commit.
